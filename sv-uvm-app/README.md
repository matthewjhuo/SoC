# sv-uvm-app — SystemVerilog, UVM & SoC 互動式學習前端應用程式

本目錄為 **SoC & SystemVerilog / UVM 互動式學習平台** 的 React + Vite 前端應用程式。完整專案說明請參閱上層根目錄的 [README.md](../README.md)。

## 常用指令

```bash
# 安裝套件
npm install

# 啟動開發伺服器 (http://localhost:5173)
npm run dev

# 打包正式環境靜態檔案至 dist/
npm run build

# 本地預覽打包結果
npm run preview
```
